# 食品饮料的批次、保质期与去向追踪

作者：杨正武
来源：https://imcoders.cn/manufacturing/food-batch-shelf-life-traceability/
发布：2026-10-15T00:00:00.000Z
更新：2026-10-15T00:00:00.000Z

沿两批原料混合、包装、出库和异常追踪，拆开食品制造的配方、设备清洗、检验、保质期与批次谱系，复算原料到九百八十袋成品的去向，并注明追溯法规的适用范围。

---


混合批次里有六成原料来自异常批，是否只追踪六成成品？如果两批原料已经混合，系统通常无法再给每袋产品指定某一批原料的独占来源。追溯需要保留混合关系，再按批准的风险评估确定处置范围。

本篇展开 I04，用冷加工混合食品的独立教学样本连接配方、清洗确认、批生产、检验和客户去向。数据均为模拟；不提供加工杀菌参数、保质期建议或食用安全判断，也不宣称覆盖所有饮料及食品工艺。

## 配方、原料状态和清洗确认共同进入开批

模拟批次 `FOOD-M01` 使用配方 `REC-F / 2`，投入原料批 A 为 600 千克、B 为 400 千克。原料身份、供应商、收货、检验状态和有效期分别保存。仓库有库存仍需核对放行与剩余有效期，不能仅按数量自动投料。

设备清洗记录 `CLEAN-F01` 绑定混合设备、执行时间、程序版本和确认结果。食品安全计划若规定额外验证，应保存相应依据；“清洗完成”按钮不能自行证明清洗效果或过敏原风险已经解除。具体控制措施和限值需要来自获准的工艺及食品安全分析。

| 系统记录 | 进入本例的内容 | 需要保留的关联 |
| --- | --- | --- |
| 配方与工艺 | REC-F / 2 | 产品、版本、批量与批准 |
| WMS 原料 | A 600 千克、B 400 千克 | 批次、状态、单位与领退记录 |
| 清洗与设备 | CLEAN-F01 | 设备、时间、程序与确认 |
| MES 批记录 | FOOD-M01 | 实际投入、工段与包装输出 |
| QMS / LIMS | 取样和检验记录 | 样品身份、方法、结果与放行决定 |

本例假定上述开批条件均已有确认记录。文章给出数据关系设计，不能把这些模拟字段当作已经执行的食品安全验证。

## 混合与包装分别建立数量关系

本批投入总量 1,000 千克，产出待包装食品 980 千克，另有 20 千克作为已登记的加工损耗。本文忽略水分变化，且损耗已计量，属于教学前提；真实蒸煮、干燥或碳酸化过程需另计质量变化与计量不确定性。

所有 980 千克以每袋净含量 1 千克完成包装，共 980 袋，包装批 `PACK-F01`。这是简化的净量示例，不代替实际净含量计量、标签或法定检验要求。原料批 A、B 都指向混合批，再由混合批指向包装批。

```text
投入 = 600 + 400 = 1000 千克
投入去向 = 包装食品980 + 加工损耗20 = 1000 千克
包装数量 = 980千克 / 1千克每袋 = 980袋
```

FDA 的[食品追溯规则说明](https://www.fda.gov/food/food-safety-modernization-act-fsma/fsma-final-rule-requirements-additional-traceability-records-certain-foods)介绍了关键追踪事件与关键数据元素，并将转换、收货和发运等事件纳入框架。该美国规则涉及 Food Traceability List 等适用条件和豁免，不能泛化为所有地区、所有食品均需执行同一规则；具体适用和现行时间安排需查看官方页面。

## 保质期与放行条件进入具体出库

本例包装记录中保存一个演示到期日 `2026-10-20`。这个日期仅用于软件判断，未做稳定性或微生物验证，不构成任何产品的实际保质期依据。真实日期应根据适用产品、加工包装、储运条件和批准规则形成。

QMS 的放行决定关联检验与批记录，WMS 按批次状态和客户所需剩余有效期选择库存。先到期先出可以减少过期风险，但不能越过隔离或客户限制。出库时保存标签身份、批次、数量和目的地。

冷链温度如果是产品要求的一部分，需保留设备、校准、采样区间、缺口和异常评估。温度数据缺失时，不应自动填成合格；单个末端温度读数也不能证明整段运输一直满足条件。

## 异常追踪先圈对象，再核对处置回执

假设原料 A 收到一条待调查异常通知。按本例混合关系，候选影响对象为整个 PACK-F01 的 980 袋，先暂停未发运库存并列出客户去向。候选范围仍需质量评估，不能直接声称食品已受污染或召回已完成。

| 包装批去向 | 数量（袋） | 后续证据 |
| --- | ---: | --- |
| 客户 X | 600 | 发运及客户收取处置通知回执 |
| 客户 Y | 200 | 发运；本样本通知回执仍待取得 |
| 企业库存 | 170 | 实际隔离应用回执 |
| 留样 | 10 | 留样位置与保管记录 |

```text
980袋 = 已发运800 + 在库170 + 留样10
已发运800 = 客户X 600 + 客户Y 200
```

查到发运数量不等于已经追回数量，客户收到通知也不等于完成实物隔离。需要继续记录在途、收货、客户库存、已使用和实际处置；未知去向保持待核实。是否实施召回及其程序，应按适用制度与授权决定。

## 复算样本保留哪些依据

[食品批次 JSON](/manufacturing/samples/food-traceability.json)保留原料投入、混合输出、损耗、包装及去向；[校验程序](/manufacturing/samples/verify-completion-samples.py)检查质量和包装数量守恒、谱系范围与未决回执。

| 依据 | 支持内容 | 边界 |
| --- | --- | --- |
| FDA 食品追溯规则官方页面 | 美国特定食品的事件与数据框架、适用性入口 | 本文没有完成该产品的法律适用性判定 |
| 本篇谱系与处置设计 | 混合批到包装及去向的核对方法 | 属于教学建模，风险范围需专业评估 |
| JSON 与校验程序 | 1000 千克和 980 袋的去向复算 | 不证明安全性、保质期或召回执行效果 |

官方页面于 2026-10-15 核对。真实项目还要取得食品安全计划、获准配方、标签、清洗验证、检验与储运依据；这些记录没有到齐时，页面应展示未决项。
