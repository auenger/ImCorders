# ERP 和仓库都有库存，到底该看哪一个

作者：杨正武
来源：https://imcoders.cn/manufacturing/erp-ewm-inventory-production-supply/
发布：2026-10-20T00:00:00.000Z
更新：2026-10-20T00:00:00.000Z

用 SAP S/4HANA 与 EWM 的生产供料场景，区分存储地点、库位、生产供料区和实际耗用，复算备料与投料后的库存，说明交货模式、PMR 模式、范围映射和回执怎样避免重复计数与错误调账。

---


ERP 显示还有一百一十件，仓库的存储区查询却只有一百件。两边都觉得对方漏记了十件，准备做盘点调整。再把生产供料区展开，才发现十件余料一直留在线边，刚才的仓库查询没有包含它。

这篇衔接[WMS 专题目录](/manufacturing/#wms)，研究 SAP S/4HANA 与 EWM 的生产供料关系。SAP 参考范围为 S/4HANA EWM 课程中的组织模型和集成模式，不把其中能力直接套到公有云仓储功能或任意旧版系统。以下数量与接口关系均为独立模拟。

## 先把存储地点和实际库位对应起来

ERP 库存管理中的存储地点，和 EWM 中的仓库、存储类型、库位承担不同层次的组织职责。EWM 可以继续管理装载单元和详细位置，两边查询前要统一工厂、物料、货主或处置权限、批次、状态、单位及截止时点。

生产供料区通常写作 PSA，用于接收或提取生产需要的材料。SAP 的[生产供料课程](https://learning.sap.com/courses/processes-in-sap-s-4hana-ewm/executing-the-production-supply-process)说明 PSA 的映射、供料方式和不同库存组织模型。PSA 与具体库位还需要结合产品等条件映射，不能把一个 PSA 名称直接当作所有实物的位置。

| 层次 | 本例对象 | 查询要覆盖什么 |
| --- | --- | --- |
| ERP 工厂与存储地点 | P100 / S001 | 本例同一范围内的全部剩余材料 |
| EWM 仓库详细位置 | 存储区 BULK、供料区 PSA | 两个区域都属于上述 S001 范围 |
| 作业任务 | 从 BULK 备料到 PSA | 实际移动和接收结果 |
| 生产耗用 | 对工单实际消耗 | 材料离开本例原料库存的依据 |

同一份库存只在约定范围中计算一次。ERP 和 EWM 都记录二百件时，不表示工厂共有四百件；它们可能是同一实物在两个系统、不同粒度下的表示。

## 两种生产集成模式不要混用单据

交货驱动模式通过相应交货对象连接供料与发料；高级生产集成则使用 Production Material Request，也就是 PMR，表达生产物料需求及相关供料、耗用关系。两种模型的适用能力和单据链不同，不能同时把同一需求下发为两套独立任务。

本篇选择教学用的 PMR 场景，并选择“同一 EWM 管理的存储地点中同时包含存储区与 PSA”的组织模型。由此，本例仓内备料不改变 ERP 存储地点总数。另一些模型会在供料时触发存储地点转移或跨仓交接，不能从本篇推导“所有备料都不需要 ERP 事务”。

SAP 的 [EWM 基础说明](https://learning.sap.com/courses/basic-customizing-in-sap-s-4hana-ewm/outlining-the-basics-of-sap-ewm)可继续对照嵌入式与分散式部署下的业务过程。部署位置并不会让单据身份、状态和实际交接证据变得多余。

## 二百件备出一百件，总库存仍是二百件

模拟工单要求供料 100 件，最初全部材料 200 件放在 BULK，没有其他收发和限制。备料任务完成并由 PSA 确认接收后，EWM 为 BULK 100、PSA 100；ERP 对应范围仍为 200。

生产随后实际耗用 90 件，按本例配置记录一次耗用，EWM 中 BULK 仍为 100、PSA 剩 10，ERP 对应原料范围为 110。产品产出另外核对，不与这份原料库存直接相加。

```text
备料后：存储区100 + PSA100 = ERP原料200
耗用后：存储区100 + PSA10 = ERP原料110
原料去向：已耗用90 + 剩余110 = 初始200
```

若仓库只读取 BULK 的一百件，与 ERP 全范围一百一十件比较，就会出现十件表面差异。调整前应先加入 PSA，核对时间与未结任务；范围不一致时不能直接批准盘亏。

## 线边退回十件，不再增加一笔工厂库存

剩余十件经身份和资格复核后，批准从 PSA 退回 BULK。本例得到 BULK 110、PSA 0，ERP 总数仍是 110。若接口把退回再次作为采购或完工收货增加十件，就会制造不存在的库存。

任务接受、拣取、到位、交接确认和耗用完成分开保存。设备已经送到但仓储回执未到时，保留未知状态并核对原任务；消息超时不能自动重派一份新的物料。供料后冻结、错批、开封超时和未用退料也要保留原批次与日期依据。

在 ERP、EWM 和 MES 都可能回报同一耗用时，要指定过账触发来源，并保留其他记录作为关联或核对。事件身份、目标物料事务和业务范围共同用于防止重复，不能只靠传输消息号。

## 对账从最小可比较的范围开始

| 场景 | 应得到的结果 |
| --- | --- |
| 完成 100 件仓内备料 | BULK 100、PSA 100、ERP 200 |
| 实际耗用 90 件 | BULK 100、PSA 10、ERP 110 |
| 查询只包含 BULK | 标注未覆盖 PSA，不直接调整差十件 |
| 十件未耗用余料回仓 | BULK 110、PSA 0，ERP 仍 110 |
| 改用不同组织或集成模式 | 重新核对映射和过账链，不沿用本例数量动作假设 |
