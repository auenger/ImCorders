用 25 块四联拼板的教学样本，串起料卷、供料器、站位表、贴装程序、板级序列号与 SPI、AOI、ICT、FCT 记录，核对接料边界、返修复测和放行回执，解释电子制造中追溯精度如何形成。

---


一卷元件接到贴片机上，扫码通过，设备继续生产。半小时后再问“这卷料贴到了哪些板上”，系统却只给出一个工单号。料卷没有扫错，追溯仍可能停在工单这一层。

[上一篇](/manufacturing/quality-incident-traceability-scope/)用合批样本说明了来源不确定时怎样圈定范围。本篇进入 I02 电子制造场景，沿 SMT（表面贴装）及后续板级测试记录往下拆。下文产线、程序和数量均为独立教学样本，未连接真实设备，也不代替产品批准的工艺与检验要求。

## 一块板需要同时带着哪些身份

工单 `MO-SMT-100` 生产 100 块控制板，产品版本为 `CTRL-C`。投入的是 25 块四联拼板，编号 P001 至 P025，每块拼板有四个有效子板位置。生产前已建立映射，例如 P013 的四块单板分别是 `P013-1`、`P013-2`、`P013-3`、`P013-4`。

本样本只讨论顶面贴装，每块单板的 U7 位号安装一颗同型号器件。没有跳板、报废或拼板位置变更，所有单板都进入了首次炉后 AOI。实际产品还有其他位号，这里只对 U7 展开料卷谱系；其他工序与物料在放行样本中假定符合批准要求。

| 对象 | 本样本中的例子 | 需要保存的关系 |
| --- | --- | --- |
| 产品与工程版本 | CTRL-C、BOM-C、工艺路线 ROUTE-C | 哪个版本允许生产，适用哪些物料与工序 |
| 拼板与单板 | P013 与 P013-1 至 P013-4 | 拼板位置、单板身份、有效性及分板后的延续 |
| 物料与料卷 | 器件 IC-7；料卷 R-A、R-B | 内部料号、制造商料号、供应商批号和独立卷号 |
| 设备与供料位置 | 贴片机 M1、供料器 F17、站位 S17 | 在哪个执行区间安装哪只供料器、装入哪卷料 |
| 程序与板面 | 贴装程序 PLACE-C.3、TOP 面 | 实际装载版本、内容校验值、位号与站位对应 |
| 检测与维修 | AOI-C.2、ICT-C.4、FCT-C.6 | 单板、测试尝试、限值版本、缺陷与复测依据 |

料号相同只能说明物料类别相同。两卷料可能来自不同制造批次；同一制造批次也可能拆成多卷。把料号当作卷号，会丢掉接料和剩余数量的边界。分卷时应生成子卷身份，记录父卷、转移数量和业务事件。

### 工程发布、现场装载与实际执行分别留痕

PLM 或工程系统发布产品结构与批准替代关系，工艺工具生成站位表、贴装程序和检测程序。MES 接收生效版本，仓储或物料系统提供料卷身份与状态，设备接口返回实际装载和执行记录。具体企业可以由一个产品覆盖多个职责，但这些记录不能省略。

对于 U7，站位表规定 IC-7 由 S17 供料。上料校验要核对当前产品版本、板面、站位、供料器与料卷身份，以及物料质量状态。若物料还受开封时限等条件约束，应读取对应的受控记录。替代料需要引用批准范围，不能只凭外观或封装相同放行。

校验通过后仍要核对设备实际加载的程序。上位机发出 PLACE-C.3，设备却保留 PLACE-C.2 时，应显示装载不一致，并按产线批准策略阻止开始新板；不能用“下发成功”替代设备确认。工单、程序名和文件校验值共同保存，避免同名程序被覆盖后无法还原历史。

## 接料边界决定能追到哪一块板

R-A 与 R-B 的物料型号相同、制造批次不同，当前均没有质量异常。两卷依次为 U7 供料。设备记录能确认 P001 至 P012 使用 R-A，P014 至 P025 使用 R-B；P013 处于接料边界，现有记录无法精确对应四个子板上的 U7。

| 板范围 | 单板数量 | U7 来源判断 | 证据精度 |
| --- | --- | --- | --- |
| P001 至 P012 的全部子板 | 48 块 | R-A | 可确定来源 |
| P013 的四个子板 | 4 块 | R-A 或 R-B | 接料边界内，逐板来源待核实 |
| P014 至 P025 的全部子板 | 48 块 | R-B | 可确定来源 |

接料扫码时间记录的是接料操作。旧料带上尚未消耗的器件、设备的供料与取料过程，可能让实际切换晚于这个时刻。因此不能把扫码之后经过产线的所有板直接归给新卷。这里的前后确定范围来自已核对的执行边界。

ASMPT 在供料校验产品说明中列出了装错或接错供料器、料卷标识错误等风险，并区分上料与视觉核对、元件电气属性验证。扫码能确认的身份条件与设备能验证的物理属性，需要分别定义。[ASMPT 供料校验说明](https://smt.asmpt.com/en/products/placement-solutions/siplace-measuring-feeder-x/)

### 将上料关系接到贴装记录上

建议用设备执行 ID 或板次 ID，把单板身份、板面、位号、站位、供料器、实际程序和料卷消耗区间关联起来。有单次贴装及料带边界证据时，可以形成较细的用料关系；只有拼板级或时间窗口记录时，就保留相应的精度。

本样本查询 R-A 的去向，得到“确定 48 块，可能再涉及 4 块”，保守候选集合为 52 块。查询 R-B 同样得到 48 块确定、4 块可能。两份候选清单相加是 104 个条目，但其中 P013 的四块重复出现，去重后仍为 100 块板。它们不会因为关联了两个候选来源而变成八块实物。

这是一组追溯查询，不代表 R-A 或 R-B 已经不合格。后文的四块挂起来自谱系完整性要求，不能据此把其他 96 块也标成质量异常。

### 双面、跳板和抛料不能藏在汇总数量里

双面产品需要把 TOP、BOTTOM 和执行次数写入记录。相同 U7 位号出现在不同板面或不同程序中，不能直接合并。跳过坏子板时应记录当次有效位置掩码；分板后的单板仍沿用原身份映射，补打标签也要保留关联。

料卷数量对账还要区分成功贴装、抛料、试料和退回。贴片机取走一颗器件，并不保证它成功留在产品上。本文只给出成功安装的 U7 来源范围，没有提供卷初始数量或抛料数据，因此不据此计算料卷库存余额。

## SPI、AOI、ICT 和 FCT 各自留下什么证据

本样本的批准路线是印刷与 SPI、贴装、回流、炉后 AOI，再进入 ICT 和 FCT。实际工厂会根据产品选择检测站、分板位置及测试顺序；双面板还会重复部分工序。

| 环节 | 核对的问题 | 建议随结果保留的字段 |
| --- | --- | --- |
| SPI 锡膏检测 | 印刷后的锡膏状态是否符合要求 | 拼板及位置、焊盘、测量值、限值与程序版本 |
| AOI 自动光学检测 | 指定检测位置的外观与装配状态是否符合要求 | 单板、板面、位号、缺陷代码、图像引用与复判记录 |
| ICT 在线电路测试 | 在测试覆盖范围内，电路及元件电气特性是否符合要求 | 单板、测试项、测量值、单位、上下限、治具和程序 |
| FCT 功能测试 | 在规定供电、负载与测试条件下，功能是否符合要求 | 单板、固件与配置、工况、步骤结果、日志及程序 |

Omron 的技术文章把 SPI、贴装后 AOI 和炉后 AOI 放在不同工序，并展示了用板级序列号与位号关联检测和贴装设备信息的方法。采集接口需要保留这些对应关系，只有总通过数很难回到具体供料器或吸嘴。[Omron 检测与贴装关联说明](https://www.omron.com/global/en/technology/omrontechnics/vol51/001.html)

ICT 与功能测试的关注范围也有区别。Keysight 将 ICT 用于板级元件和电气连接等检查，功能测试关注设备整体行为。具体能覆盖什么，仍取决于测试可达性、治具、程序和产品设计，某一站 PASS 不能替代其他必经项。[Keysight ICT 说明](https://www.keysight.com/se/en/products/in-circuit-test-for-manufacturing/in-circuit-test-systems.html)

### 每次检测独立记录，返修再通过也留着第一次失败

样本在同一截止时点统计如下。SPI 和其他前序要求已满足；AOI 的三块首次失败板经过人工确认，均需要维修，不包含误报改判。

| 站点 | 首次进入的唯一单板数 | 首次通过 | 首次失败 | 截止时点的后续结果 |
| --- | --- | --- | --- | --- |
| 炉后 AOI | 100 | 97 | 3 | 两块维修复测通过，一块待处理；共 99 块可进入 ICT |
| ICT | 99 | 98 | 1 | 一块未解决，98 块进入 FCT |
| FCT | 98 | 97 | 1 | 一块未解决，97 块完成规定检测 |

AOI 首次失败的三块是 P006-2、P013-3、P022-1。前两块分别维修 R12、R18 焊点并复测通过，未更换 U7，也没有解决 P013 的 U7 来源缺口。P022-1 仍停留在维修待办。ICT 未通过的是 P018-4，FCT 未通过的是 P020-1。

首次 AOI 通过率为 `97 / 100 = 97%`，维修后的 AOI 累计通过比例为 `99 / 100 = 99%`，两个口径分别保存。不能把两次复测通过加进首次通过数，也不能把 102 条 AOI 检测尝试当成 102 块板。ICT 的分母是实际进入的 99 块，FCT 的分母是 98 块。

每次尝试保存独立的 `attempt_id`，重复上传同一次尝试按来源事件 ID 去重。记录包含原始判定、程序与限值版本、检测时间和接收时间；维修单再引用缺陷、措施及复测尝试。如果确需换元件，应新增拆除和换入的谱系关系，不覆盖原用料。

## 97 块检测通过，为何只有 93 块可以继续流转

工艺与质量人员为这个样本批准的规则要求：必经检测完成、返修有闭环记录、板级谱系完整，并且不存在有效质量限制。四块 P013 子板的所有规定检测都已通过，但接料边界没有补齐，因此被挂起。它们仍需取得补充证据或按权限完成例外评审，才能继续流转。

这个完整性检查设置在最终流转关口。此前的受控测试允许继续执行，所以 P013 可以完成 ICT 和 FCT；挂起后不允许把它们转为可出货状态。若实际企业要求在贴装后立即拦截，测试投入数量就会不同，需要按实际路线重算。

| 截止时点状态 | 唯一单板数 | 对应对象 |
| --- | --- | --- |
| 已满足样本流转规则并取得 MES 回执 | 93 | 完成检测且不存在挂起的单板 |
| 检测通过，谱系待核实 | 4 | P013-1 至 P013-4 |
| AOI 维修未完成 | 1 | P022-1 |
| ICT 异常未解决 | 1 | P018-4 |
| FCT 异常未解决 | 1 | P020-1 |
| 合计 | 100 | 每块板只计入一个当前状态 |

本样本均未发运。“93 块可流转”描述 MES 在这个关口的结果，后续装箱、订单分配与发运仍有各自的条件。最终统计按单板集合核对：`93 + 4 + 1 + 1 + 1 = 100`。

### 接口断连时保留未决状态

设备上传了 PASS，但消息里的单板编号无法匹配，应进入待关联队列并保留原始记录。不能默认挂到“当前工单的下一块板”。程序版本、板面或拼板位置缺失时，也要显示证据不完整。

事件需要分别保存发生时间、接收时间、来源序号和设备身份。跨设备时钟有偏差时，优先使用板次、执行 ID 和已验证的业务关联；时间窗口只能提供它能支持的精度。离线补传后按事件 ID 去重，检测履历和谱系重新评估，保留此前结论版本。

放行指令还要读取当前限制版本。质量挂起在检测通过后到达时，MES 应按批准策略撤销未执行的流转许可或阻止后续动作，并记录结果。若产品已经转移，回传实际位置，由质量流程接着处置，不能靠修改一条 PASS 记录补救。

## 用板级样本验收电子制造接口

可下载[SMT 板级追溯样本](/manufacturing/samples/smt-board-traceability.json)。其中列出 25 块拼板与 100 个单板身份、U7 候选来源、检测尝试、维修记录和当前状态，便于将接口输出与正文逐项对照。程序版本和单据编号均为教学数据。

| 独立验收变化 | 应得到的结果 |
| --- | --- |
| 基准查询 R-A | 确定 48 块、另有 4 块可能，候选去重后 52 块 |
| 合并 R-A 与 R-B 两份候选清单 | 去重后 100 块，P013 的四块不会重复计数 |
| 仅收到接料扫码时间 | P013 的逐板来源仍未知，不自动分给新卷 |
| 补充可信执行记录，证实 P013-1、P013-2 来自 R-A，其余来自 R-B | 两卷各确定关联 50 块；更新谱系并重新评估四块挂起，不直接伪造放行回执 |
| 重复发送 P006-2 的同一次 AOI 复测 | AOI 尝试数与板数不增加，首次通过率仍为 97% |
| 将贴装程序装载回执改成 PLACE-C.2 | 与发布包不一致，按批准策略阻止新板执行并登记偏差 |
| 丢失一块板的拼板位置或板面 | 返回待关联，不能借用相邻板的检测结果 |
| 检测全部完成，但 P013 谱系仍未补齐 | 97 块检测通过，93 块取得样本流转回执，4 块继续挂起 |
| 复测通过记录先到，维修记录后到 | 先显示维修证据待补；关联完成后再按规则重新评估 |

这份样本留下两个需要现场确认的接口能力：设备能否提供接料实际生效的执行边界，检测结果能否稳定关联到单板、板面和位号。只有工单总数和一个 PASS 字段时，本文的逐板结果还无法计算，应把缺失字段列入采集改造范围。

下一篇回到 S06 工单实际成本，沿材料耗用、工时、返修与分摊记录，核对数量差异和计价差异怎样进入同一张成本明细。
