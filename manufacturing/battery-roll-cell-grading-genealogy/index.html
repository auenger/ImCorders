电池制造怎样连接极卷、单体与分档

用极卷区间到单体身份的模拟映射，连接缺陷定位、装配、化成测试、分档和模组组成，复算隔离与报废去向，说明位置谱系、测试尝试和电池护照之间的范围差异。

涂布线发现一段缺陷，后续单体却已经进入化成。若系统只保存“使用过这卷材料”，往往只能隔离整卷关联的所有单体；若声称能精确到米，又需要证明卷长坐标、分切、转向和装配映射没有丢失。

本篇展开 I07 的电池部分，重点是极卷区间、单体、测试与模组的记录关系。所有长度、容量、数量和分档条件均为教学模拟，不提供电芯制造参数、化成规程或安全使用判断。

极卷身份还需要位置和转换关系

浆料批、涂布卷、分切子卷和单体各有身份。分切可能改变幅宽、方向、起点和数量，连接时应保留所用区间与转换依据。长度坐标还需要说明零点、编码器标定、接带、伸缩和切边条件。

ORNL 的涂布缺陷研究摘要描述了其针对特定材料和试验电芯引入涂布缺陷的研究。它支持关注缺陷与后续性能的关系，不能推广成“所有缺陷必然导致相同失效”或本篇的通用判废阈值。

本例简化为单条可追踪极片长度 100 米，每个教学单体消耗一个独立的 1 米区间，C001 对应 [0,1)，C100 对应 [99,100)。忽略分切宽度、双面、多极片及其他组件，只演示位置集合的相交计算；真实电芯结构不能照此建模。

映射记录本例条件真实项目需补充
原卷 ROLL-B01100 米坐标测量和起点依据
单体 C001—C100每个映射一段 1 米区间实际切片或卷绕消耗关系
缺陷 DEF-B01区间 [20,25)检测方法、位置精度与误差边界
映射版本 MAP-B / 1无接带和坐标反转实际转换和接带履历

缺陷区间先形成候选隔离集合

半开区间相交后，本例候选单体为 C021—C025，共五个。C020 使用 [19,20)，C026 使用 [25,26)，均不与缺陷区间相交。这个精确集合依赖前述无误差映射前提。

候选范围 = 与[20,25)有非零重叠的单体区间
候选单体 = C021、C022、C023、C024、C025
候选数量 = 5

真实位置误差需按批准方法扩大候选区间，映射缺失时也要保留未知关联，不能把未匹配对象当成没有风险。候选隔离表示等待评估，不意味着已经证明五个单体均不合格。

本样本在化成前隔离这五个，其他九十五个进入测试。隔离决定与线体、库存实际应用回执分别保存；若单体已经进入模组，应继续正向追踪，不能只改变原卷状态。

测试、复测与分档保留独立版本

九十五个测试对象中，九十个取得本例所需的通过结论，三个待评估，两个已批准并执行报废。各记录绑定单体、设备通道、方法版本和测试尝试。复测保留原始结果及采用依据，不能只留下最好的数值。

为演示分档，给九十个通过对象配置独立的教学容量值：六十个为 3.10 Ah，三十个为 3.00 Ah。规则 GRADE-B / 1 将不低于 3.05 Ah 的对象分为 A 档，将 [2.95,3.05) Ah 分为 B 档。这里的档位只是软件示例，不能替代真实容量方法、安全要求或客户分选条件。

100个单体 = 前段隔离5 + 测试通过90 + 待评估3 + 报废2
90个通过对象 = A档60 + B档30

测试通过条件与分档条件分开保存。本例只有已经通过的对象才进入分档，不能用容量达到某档直接覆盖其他未完成的检测。化成、老化、内阻与其他实际要求是否适用，需由产品和工艺依据确定。

模组组成接回逐个单体

样本每个模组装十个同档单体，形成 A 档模组六个、B 档模组三个，共九个模组。九十条安装关系记录单体身份、模组身份、位置与时间；单体不能同时存在于两个当前有效模组中。

本篇没有给出完整模组安全测试和放行依据，因此只称“完成组成关系登记”，不宣称九个模组已经可销售。换件、拆解和返工应建立新的配置生效记录，并保留原始组成。

电池护照涉及生命周期信息与访问规则，生产谱系可以成为其中的来源之一，但内部一张追溯表不能自动满足全部要求。本文不展开其法规适用、实施时间或数据点清单，避免把生产案例当成合规实现。

用位置、数量和组成三组关系验收

电池谱系 JSON保存一百个单体区间、测试去向、模拟容量和模组位置；校验程序复算缺陷相交、分档和唯一安装。
