汽车零部件的质量策划怎样进入生产

把汽车零部件的过程流程、风险分析、控制计划、量测与生产记录接到同一特征身份，说明版本切换、抽样边界、不合格隔离和客户批准的证据关系，附百件批次的教学样本。

控制计划已经换版，检验终端还在用旧的特征编号。五个抽检结果里有一个超限，报表却把其余九十五件写成合格。文件发布与现场执行之间如果没有稳定的特征身份，质量策划就很难回到具体产品。

本篇展开 I03，以轴套的一项尺寸检查为独立教学案例。所有尺寸、样本量和处置条件均为模拟，不能用于真实零部件生产；文章不复述付费标准全文，也不替代客户专有要求与适用法规评估。

把策划文件连到同一个特征

过程流程描述工序顺序，过程风险分析说明可能的失效及控制考虑，控制计划定义现场控制安排，作业与检验记录留下执行事实。它们需要通过产品、工序和特征身份关联，不能仅以文件标题相同判断一致。

AIAG 的APQP 与控制计划资料入口明确列出 APQP 第三版与控制计划第一版，并提供相关培训和资料。这只能证明其公开产品与版本信息；本文不据此声称掌握或逐条满足手册要求。

APQP、FMEA、MSA、SPC、PPAP 各有用途。一个工具完成不能自动证明其他工具通过。客户要求的提交、批准、让步或更改通知，需要按实际客户和项目保存依据，不能预设所有汽车客户采用同一套表单与时限。

控制计划生效要落到生产范围

本例控制计划 CP-A / 2 对 LOT-A01 生效，MES 任务保存该版本及其内容摘要。检验终端读取 F10 的适用要求，而非运行时寻找“版本号最大”的文件。尚在执行的旧批次如何切换，保留变更评估和适用决定。

量具 G-A01 的校准状态与量测方法适用性分别记录。本样本假定方法评估和量具条件已获批准，但没有提供真实 MSA 研究，也不宣称量测系统已达到某个行业百分比门槛。缺少相应依据时，现场准备状态应保留待确认。

供应商来料、生产工装、程序参数与操作者条件都可能改变过程解释范围。追溯数据可以协助定位影响对象，是否需要重新批准或追加验证，由实际要求决定。审批日志应指向对象和版本，不能只留一条“主管已确认”。

五个测量值只能说明已测的对象

教学批次含序列号 A001 至 A100，共一百件。样本要求 F10 为 20.00 毫米，允许区间 [19.95, 20.05] 毫米，端点包含在内。这些数值仅供复算，来源是本文明确设定。

五个已测对象有四个区间内、一个超限；另外九十五件未测，不能登记为九十五件合格。这个样本也不足以建立过程稳定性或计算可信的过程能力结论，本文不输出 Cpk 或批次接受概率。

样本反应规则 REACTION-A / 1 规定，出现超限即暂停本批放行并创建不合格记录。该规则为教学设定，不能理解成所有零件都应使用相同的抽样和反应方案。实际取样数量与频率必须有批准依据。

隔离范围与实物不合格数量分开

NC-A01 关联测量 MEAS-03，记录一个已观测超限对象。因当前证据不足以缩小范围，本样本把整个 LOT-A01 的一百件设为待评估隔离，形成库存状态应用回执。隔离一百件不表示已证明一百件均有尺寸缺陷。

后续可按批准方案追加检查、分析测量系统、评估工装或过程变化，再决定返工、报废、让步或放行。原始测量结果保留，复测增加新尝试。客户让步如适用，需要对象、数量、有效期和接受证据；系统不能根据一个勾选框推导客户已同意。

质量记录还应回查来料批次和已交付对象。若故障发生后仍有发运，隔离回执要与实际库存、发运截止点一起核对，不能仅凭 QMS 状态就宣称客户风险已经消除。

核对来源和不能从样本推导的结论

汽车零部件样本 JSON提供一百件身份和五次测量；校验程序按区间复算超限对象，并区分已测、未测与隔离集合。

依据支持内容限制
AIAG 官方 APQP / CP 入口公开的工具名称、版本及资料入口未读取付费手册全文，不引用具体条款
本文关系设计特征、版本、执行与回执的可追踪连接属于实施建议，需适配项目
JSON 与校验程序4 个区间内、1 个超限、95 个未测、100 个隔离不能证明批次合格率或过程能力
