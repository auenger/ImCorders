Neuro-IDE：重构 AI 开发体验

分享 Neuro-IDE 的设计理念，探讨如何打造以 Markdown 为核心的 AI 原生开发环境

节目简介

Neuro-IDE 是一个以 Markdown 文档为核心、多角色 CLI 为引擎的桌面端 AI 开发环境。本期播客分享了 Neuro-IDE 的设计理念和实现思路。

设计初衷

大多数 AI 工具以命令行形式存在，开发者需要在终端和 IDE 之间频繁切换，导致上下文割裂、状态难以保持。

Neuro-IDE 的定位是成为开发者与 AI 工具链之间的中间层。通过将碎片化的命令行交互转化为持久化、可视化的 IDE 元数据，让 AI 成为开发者的深度协作伙伴。

核心特性

多角色终端系统

在 AI 辅助开发中，不同技术领域的问题需要不同的上下文和角色定位。每个角色对应一个独立的 pty 进程，后台进程始终保持 Keep-Alive 状态。

架构师角色负责整体设计、技术选型、架构决策。前端角色负责 UI 组件、样式、用户交互。后端角色负责 API 设计、数据库、业务逻辑。

三栏布局设计

左侧占 20% 宽度，包含角色切换器和智能文件树。中间占 40% 宽度，是 Markdown 画布和对话流控制台。右侧占 40% 宽度，是 Monaco 代码编辑器，AI 改代码时自动切换为 Diff 对比视图。

文件拖拽注入

从左侧文件树拖拽文件到中间 Markdown 编辑器，UI 显示为胶囊形式。后台自动向当前激活的 CLI 发送添加文件指令，AI 获得文件上下文后可以进行针对性分析和修改。

技术实现

前端使用 React + Tailwind CSS 负责 UI 交互。后端使用 Electron + Node.js 负责系统 I/O。中间件使用 node-pty 终端模拟和 chokidar 文件监听。

检测到文件变更事件且当前处于 AI 生成状态时，右侧栏自动锁定并展示 Diff 对比视图，提供 Accept 和 Reject 按钮。
